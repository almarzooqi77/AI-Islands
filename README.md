# AI Islands

A playful game that explains how modern AI works, in English and Arabic. Sail two voyages of islands, play one
short mini-game per idea (next-word guessing, tokens, hallucination, RAG, prompt injection, deepfakes, bias and more),
then collect the card and a certificate.

**Play:** open the GitHub Pages link of this repository. Nothing to install; stars are saved in your own browser.

Run locally: any static file server in this folder, for example `python -m http.server`, then open http://localhost:8000.

Plain HTML, CSS and JavaScript, no build step and no dependencies. Font: Baloo Bhaijaan 2 (SIL Open Font License).
